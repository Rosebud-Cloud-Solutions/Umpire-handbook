About

How this handbook works.

Point of truth: every ruling in this app is grounded verbatim in the World Netball — Rules of Netball, 2024 Edition. Rule references in square brackets, e.g. [13.1], point to the exact clause. Where translated wording diverges, the English text is authoritative.

What it does today

This is the first working prototype — a single, self-contained web page you can open in a browser or host as a static site (e.g. Azure Static Web Apps). It contains three tools:

  • Scenario Assistant — describe a situation and get the matched ruling with sanction, terminology, position, signal and procedure.
  • Rulings Library — browse and search every infringement by category.
  • Hand Signals — the 23 official umpire signals.

The assistant currently matches your description against a curated, rules-grounded knowledge base entirely on your device — nothing is sent anywhere. This keeps every answer traceable to a specific rule, which is exactly what an umpiring aid needs.

Answers are laid out in the same structure umpires are marked on in the Europe Netball ‘A’ & ‘B’ written assessment: the infringement (rule name and heading), the sanction/action, who it is awarded to, and where it is taken — followed by the procedure and hand signal.
